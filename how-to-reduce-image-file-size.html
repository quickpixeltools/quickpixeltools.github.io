How to Reduce Image File Size Without Losing Too Much Quality

Large image files can take longer to upload, download and display. Reducing image file size can make images easier to share and can help web pages load more efficiently. The key is to reduce unnecessary data while keeping the image visually useful.

What Is Image File Size?

Image file size is the amount of digital storage required by an image. It is usually measured in KB or MB. For example, an image may have a file size of 250 KB, 1 MB or several megabytes.

File size is affected by several factors, including image dimensions, format, image content, compression settings and the amount of detail contained in the image.

Two images with the same width and height can have very different file sizes because they may use different formats or compression settings.

Why Should You Reduce Image File Size?

Reducing unnecessary image data can be useful in many situations. Smaller files are generally easier to store and share and may require less bandwidth when transferred over the internet.

Common reasons to reduce image file size include:

  • Uploading images to websites
  • Sending images through messaging services
  • Reducing storage usage
  • Making email attachments smaller
  • Preparing images for online forms
  • Improving the efficiency of image-heavy web pages
  • Preparing photos for social media or online platforms

Compression vs Resizing

There are two common ways to make an image file smaller: compression and resizing.

Method What It Changes Best Used For
Compression Reduces image data Keeping the same dimensions
Resizing Changes width and height Images that are unnecessarily large
Format conversion Changes the way image data is stored Choosing a more suitable format

In many cases, using a combination of resizing and compression can produce a much smaller file than using either method alone. For more details about compression, you can also read our guide How to Compress an Image Without Losing Too Much Quality.

1. Compress the Image

Image compression reduces the amount of data stored in the image. Depending on the format and settings, compression can reduce file size while keeping the image visually similar to the original.

For example, a large JPG photo may be compressed to a smaller file without making the difference immediately noticeable.

The amount of compression you should use depends on how the image will be used. A photograph displayed on a website may tolerate more compression than an image containing small text or detailed graphics.

2. Resize Images That Are Too Large

If an image has much larger dimensions than necessary, resizing it can significantly reduce the final file size.

For example, if an image is 5000 pixels wide but only needs to be displayed at around 1200 pixels wide, keeping the original dimensions may be unnecessary.

3. Choose the Right Image Format

The image format can have a major effect on file size. JPG, PNG and WebP are commonly used formats, but they are designed for somewhat different purposes.

If you are unsure which format is appropriate, our guide JPG vs PNG: Which Image Format Should You Use? explains the main differences between these two common formats.

Format Common Use General Characteristics
JPG Photos Good compression and widely supported
PNG Graphics, screenshots and transparency Can preserve sharp details and transparency
WebP Web images and modern websites Can provide efficient compression with good visual quality

There is no single format that is best for every image. The right choice depends on the image content and where it will be used.

JPG Images

JPG is commonly used for photographs because it can significantly reduce file size compared with an uncompressed image.

However, JPG uses lossy compression. Repeatedly saving an already compressed JPG can introduce additional visual artifacts.

JPG is often a practical choice for photographs, product images and other images containing many colors and gradients.

PNG Images

PNG is useful when preserving sharp edges, text, graphics or transparency is important.

PNG files can sometimes be considerably larger than JPG files, especially when used for detailed photographs.

If a PNG photograph is much larger than necessary, converting it to a suitable JPG or WebP image may reduce the file size substantially, although the result depends on the image and settings.

For a more detailed comparison, see JPG vs PNG.

WebP Images

WebP is a modern image format designed to provide efficient image storage for web use.

Depending on the source image and compression settings, a WebP image may be smaller than a comparable JPG or PNG while maintaining useful visual quality.

For websites where browser compatibility and workflow requirements allow it, WebP can be an option worth considering.

You can learn more about this format comparison in JPG vs WebP: Which Image Format Is Better?.

How to Reduce an Image to 100KB

Sometimes an online form or website requires an image to be below a specific file size, such as 100KB.

There is no universal setting that will make every image exactly 100KB. The required settings depend on the original dimensions, format and image content.

A practical approach is:

  1. Check the original image dimensions.
  2. Resize the image if its dimensions are unnecessarily large.
  3. Compress the image.
  4. Check the resulting file size.
  5. If necessary, adjust the compression settings further.
  6. Check the image visually before using it.
Important: Trying to reach an exact file size can require several adjustments. Do not reduce quality more than necessary just to reach a particular number.

How to Reduce an Image to 200KB

The same general method can be used when an image needs to be below 200KB.

A 200KB target gives you more room than a 100KB target, but the result still depends on the original image.

For a large photograph, resizing the dimensions first can make it much easier to reach the desired file size while maintaining reasonable visual quality.

Compression Does Not Always Mean Better

The smallest possible file is not always the best result. Over-compressing an image can create visible artifacts, blurry details, blockiness or loss of fine information.

The goal should be a reasonable balance between file size and visual quality.

For important photographs, documents or graphics, always inspect the compressed result before deleting or replacing the original.

Common Mistakes When Reducing Image Size

1. Compressing Too Aggressively

Using extremely strong compression may produce a very small file, but the image can become visibly degraded.

2. Resizing More Than Necessary

Making an image extremely small may reduce file size, but it can also make the image unsuitable for its intended purpose.

3. Using PNG for Every Photograph

PNG can be useful for graphics and transparency, but it may not be the most efficient choice for photographs.

4. Converting Formats Without Checking the Result

A format conversion can change both file size and image characteristics. Always compare the result with the original before using it.

5. Deleting the Original Too Early

Keep the original image until you have confirmed that the compressed version has the quality and dimensions you need.

Image File Size and Website Performance

Images can represent a significant portion of the data loaded by an image-heavy web page. Using appropriately sized and compressed images can help reduce unnecessary data transfer.

However, image optimization is only one part of website performance. Other factors such as scripts, fonts, page structure and hosting can also affect loading speed.

The best approach is to use images that are large enough for their actual display size without keeping unnecessarily large originals on the page.

Reducing Image Size on Mobile

Mobile devices can also benefit from smaller image files. Smaller files can be easier to upload, share and store, particularly when internet bandwidth or storage space is limited.

When preparing an image on a phone, first consider whether the image needs its original camera resolution. A modern smartphone can produce very large photographs that are much bigger than necessary for a profile picture, website thumbnail or online form.

Quick Tips for Smaller Image Files

  • Resize images to dimensions appropriate for their actual use.
  • Compress photographs before uploading them.
  • Choose JPG, PNG or WebP based on the image type.
  • Avoid repeatedly editing and saving lossy images.
  • Keep the original image as a backup.
  • Check both file size and visual quality.
  • Do not reduce an image more than the intended use requires.

Frequently Asked Questions

How can I reduce image file size?

You can reduce image file size by compressing the image, resizing its dimensions, choosing a suitable format, or combining these methods.

Does reducing image size reduce quality?

It can. Compression and resizing may affect image quality depending on the settings used. Moderate optimization can often reduce file size while keeping the image visually useful.

Is WebP always smaller than JPG?

No. WebP can often produce smaller files at similar visual quality, but the actual result depends on the image and compression settings.

How can I make an image smaller than 100KB?

Try resizing unnecessarily large dimensions and then compressing the image. If needed, adjust the compression settings or consider another suitable image format.

What is the difference between compression and resizing?

Compression reduces the data used to store an image, while resizing changes the image's width and height. Both methods can reduce the final file size.

Final Thoughts

Reducing image file size is usually about finding the right balance between file size, dimensions, format and visual quality.

For many images, a simple combination of sensible dimensions and moderate compression is enough. When a specific file-size limit is required, such as 100KB or 200KB, you may need to test a few settings until you find a result that meets the requirement without unnecessarily damaging the image.
